# 🧩 Browser Extension Manager UI

Este proyecto forma parte de un desafío de [Frontend Mentor](https://www.frontendmentor.io) centrado en diseñar una interfaz para gestionar extensiones del navegador. Se desarrolla inicialmente como una práctica de frontend y se expandirá a una aplicación fullstack funcional.

## 🎯 Objetivos del challenge

- Crear una interfaz visual atractiva para mostrar extensiones del navegador.
- Practicar con datos dinámicos y filtros visuales.
- Usar diseño responsive basado en grid.
- Aplicar theming de colores y buenas prácticas de UI.

---

## 🚀 Expansión del Proyecto

Una vez completado el diseño base, este proyecto se extenderá hacia una aplicación completa que simula la gestión de extensiones con autenticación de usuario, persistencia de datos y despliegue en servidores reales.

### ✅ Checklist de mejoras para la versión extendida

#### 🖼️ Frontend (Angular)

- [ ] Conectar con API backend para cargar extensiones dinámicamente.
- [ ] Implementar filtros avanzados y barra de búsqueda.
- [ ] Agregar modo claro/oscuro.
- [ ] Animaciones suaves para transiciones de UI.
- [ ] Vista de detalles de cada extensión.
- [ ] Soporte multilenguaje (i18n).

#### ⚙️ Backend (Java + Spring Boot)

- [ ] Crear una API REST con controladores, servicios y repositorios.
- [ ] Endpoints para CRUD de extensiones.
- [ ] Registro e inicio de sesión de usuarios con tokens (JWT).
- [ ] Validaciones y manejo de errores.

#### 🗃️ Base de datos (PostgreSQL)

- [ ] Modelado de entidades (usuarios, extensiones).
- [ ] Relaciones y validaciones a nivel de base de datos.
- [ ] Migraciones automáticas con Flyway o Liquibase (opcional).

#### 🌐 Infraestructura

- [ ] Deploy de frontend (Netlify, Vercel o Firebase Hosting).
- [ ] Deploy de backend (Render, Railway o Fly.io).
- [ ] CI/CD básico con GitHub Actions.
